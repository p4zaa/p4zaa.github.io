# p4zaa.github.io

## หน้าแรกใหม่

หน้าแรกที่ `/` เป็นแลนดิ้งเพจมินิมอล (ไฟล์ `index.html` ที่ราก ไม่มี Jekyll front matter จึงไม่ถูกห่อด้วยเลย์เอาต์เดิม)

เว็บไซต์เดิมยังอยู่ครบที่ `/classic/`

ถ้าต้องการใส่โลโก้หรือตัวการ์ตูนของตัวเอง ให้แทนที่ไฟล์ `assets/landing/logo.svg` และ `assets/landing/character.svg` (ใช้ชื่อไฟล์เดิม หรือแก้ `src` ของรูปในหน้าแรก — ใช้ PNG/GIF/APNG ก็ได้)
